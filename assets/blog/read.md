
# Description

- On commence par créer un article en markdown afin que ce soit lisible
- On fait une copie du template
- On adapte ensuite le markdown au template
- On met la copie tu template dans le dossier articles
- Par défaut la vidéo est en commentaire, il faut l'activer s'il y en a une

## Le dossier styles
Il contient les fichiers css

## Le dossier scripts
Il contient les fichiers js

## Le dossier images
Il contient les images des articles

## Le Dossier articles_ok
Il contient les fichiers markdown qui ont déjà été publiés
